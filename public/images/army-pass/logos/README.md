# Assets de logos

ARIRANG usa o logotipo completo fornecido pelo usuário em `arirang-logo-novo.jpeg`, com o símbolo e a escrita ARIRANG preservados. A marca preta BTS permanece em `bts-logo.png`. O uso foi solicitado especificamente no template ARIRANG; não foi estendido aos outros templates. O original do logotipo anterior está preservado como `arirang-logo-original.jpg`.

Os PNGs com transparência são preparados por `node scripts/prepare-arirang-logos.mjs`, sem redesenhar, recolorir ou gerar formas. O script remove somente o fundo quase branco neutro e as margens vazias. Detalhes e posições: `docs/arirang-logo-fix.md`.

As identidades de WINGS, MAP OF THE SOUL: 7 e PERSONA e o cadastro BTS compartilhado continuam pendentes. Não adicionar substitutos fictícios nem estender a referência de uso destes arquivos a outras finalidades. O cadastro está em `src/features/army-pass/themes.ts`.
